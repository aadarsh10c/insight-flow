Anatomy
  • Dialog: ~90vw × 90vh, L3 elevation, header with Reset All / Cancel / Save Chart.
  • Body: 40% config left (scrollable) · 60% preview right (no scroll, chart fills).
  • All 4 steps always visible as cards in the config column. Each card has 3 visual states:
    • Locked (grey, opacity 55%, padlock icon, body hidden) — previous step not complete
    • Active (accent border + soft glow, dot icon, body open showing controls) — currently editable
    • Complete (green check icon, body hidden, summary line shows selection) — clicking re-expands for edit; cascade rules reset downstream
  • Step 3 filter system:
    • Each filter = one row with [Column dropdown] [Value dropdown] [×]
    • Multiple filter rows = AND. Subtle "AND" divider rendered between rows.
    • "+ Add filter" button (dashed accent border) below the rows
    • Single value per row in V1; multi-value (Region IN [W, E]) is V2
    • Step is optional — empty = no filters applied; user just leaves it untouched and moves on
  • Line chart period selector (top-right of preview):
    • Only rendered when chart type is Line. Replaces the "View as" Step 2 control from v1.
    • Dropdown shows Daily / Weekly / Monthly / Quarterly / Yearly (smart-filtered: invalid buckets disabled in the open dropdown)
    • Lives in the preview-card header beside the chart title
    • Default picked by the system; user can switch to refine view without re-opening the config column
  • Save: enabled when Step 1 + Step 2 are both complete. Steps 3 + 4 stay optional.
  • Reset All: wipes all steps, emits a 5-second "Undo" toast.
