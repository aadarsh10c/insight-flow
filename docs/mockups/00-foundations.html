2 · Border radius scale

Five steps. Pick by element type, not by feeling.
sm · 4px
tags, badges, dividers-as-pills
md · 8px
buttons, inputs, small chips
lg · 10px
cards, panels (default)
xl · 12px
modals, dialogs, large cards
full
avatars, dots, pill buttons

4 · Focus rings · keyboard accessibility

Two patterns — one for solid elements (buttons), one for input fields. Always focus-visible only, never on mouse click.
Solid button (outer ring)
focus-visible:ring-2 ring-offset-2 ring-accent/50
Input field (inner glow + border swap)
border becomes accent + soft glow ring
