Anatomy
  • Sidebar: brand · 4 nav items (Settings disabled with tooltip "Coming soon") · theme cycler at bottom
  • Page header: title "Data Sources" + count subtitle + primary "+ Add data source" button right-aligned
  • Table: 5 columns — Name · Size · Type (CSV/XLSX pill) · Uploaded (relative) · Actions
  • Green tick: persistent on most-recently-uploaded data source. Only one tick at a time. Survives refresh.
  • Row action: "Create Report" — accent-colored, jumps to /reports with the data source pre-selected in the Add Report dialog
  • No delete action in V1 (documented in whitepaper §15)
  • Empty state: friendly icon + heading + nudge to use the primary CTA
Open questions worth deciding now
  • Should the row also be clickable (entire row navigates somewhere — like a preview)? Currently only the "Create Report" button is actionable.
  • Should clicking the file name show a preview (first 10 rows + inferred types) before creating a report? Or is that V2?
  • Tick color: success green (#15803d) — or should it match the accent (orange)? Orange might compete with the "Add" button. Recommend keep green.
