Anatomy
  • Backdrop: page dims to 55% black + subtle blur, dialog floats at L3 elevation
  • Header: serif title + small description with the cap reminder
  • Drop zone: dashed border in default state, becomes a solid card with file icon + name + size + "Change" when a file is picked
  • Name field: auto-pre-fills with filename (extension stripped) — fully editable
  • Footer actions: Cancel (outline) + Add data source (primary, disabled until both file and name are set)
  • Error states: inline error message below drop zone, drop zone gets a red border, primary action disabled
