Anatomy
  • Sidebar: Reports active
  • Page header: title "Reports" + count subtitle + "+ Add Report" primary button right
  • Table columns: Name · Description (truncated to ~80 chars, "—" if empty) · Data source name · Created (relative time) · Actions
  • Row is clickable — entire row navigates to /reports/:id on click (hover state: subtle warm cream background)
  • Delete action: destructive-colored trash icon button, right-aligned. Click stops row navigation, opens ConfirmDialog
  • ConfirmDialog: serif title "Delete report '<name>'?" + muted "This cannot be undone." + Cancel (outline) / Delete (destructive)
  • Empty state: file-text icon, "No reports yet", nudge text
Open questions
  • Show "Last modified" instead of (or in addition to) "Created"? Currently just Created.
  • Empty description shows "—". OK, or leave blank?
  • Sort order: most-recently-created first (default), or alphabetical? Currently most-recent first.
  • Should there be a search/filter on the list? Probably V2.
