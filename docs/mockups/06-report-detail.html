Anatomy
  • Breadcrumb top-left: "Reports › Report Name" — link back to /reports
  • Header row: editable Name (serif, large) + editable Description (sans, muted) on the left; primary button on the right
  • Inline-editable Name + Description — no separate "Edit" button. Click anywhere in the field to edit. Auto-saves on blur. Focus state shows a thin accent bottom border.
  • Metadata row: data-source tag (with database icon) + "Last modified X ago" below the description
  • Primary button: "Add Widget" (plus icon) when no chart · "Edit Widget" (pencil icon) when chart exists
  • Canvas: single card at L2 elevation, takes the rest of vertical space, contains either empty-state OR the chart
  • Chart card: serif chart title + Plotly chart fills available space. Auto-resizes with the window.
  • Empty state: bar-chart icon (muted accent), heading "No chart yet", nudge "Click 'Add Widget' to build your first chart for this report."
Open questions
  • "Add Widget" → "Edit Widget" labels: OK, or keep "Add Widget" as label even after a chart exists?
  • Breadcrumb at top — useful, or noise? Could be replaced by a "← Reports" back link in the sidebar/header.
  • Data source tag in the metadata row — OK placement, or should it be more prominent?
  • Description placeholder text: "Add a description…" — OK?
  • Should there be a "Last modified" timestamp shown live, or just on load? Currently shown as static "5 minutes ago".
