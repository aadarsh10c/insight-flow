Anatomy
  • Dialog: max-width 720px (wider than upload dialog because of the column table). Vertical scroll when content overflows. L3 elevation.
  • Section 1 — Data source: dropdown of existing data sources. Pre-selected if coming from /datasources "Create Report". No inline upload (deferred to V2).
  • Section 2 — Name + Description: single-line text input + multi-line textarea (optional). Save disabled until both Name and Data source are set.
  • Section 3 — Columns: compact table with Name input (rename), Type select (Text/Number/Date — system-inferred default, user can override), Ignore action right-aligned.
  • Ignored columns section: expandable accordion at bottom. Click to reveal ignored columns; each has a Restore action. Closed by default; auto-expanded if there are ignored columns (or kept closed — open question below).
  • Empty data-source state: If user has zero data sources, dialog shows a hint linking to /datasources. Save remains disabled.
  • Footer: Cancel (outline) + Save report (primary). On save → dialog closes → routes to /reports/:newId.
Open questions
  • "Ignored columns" section: open by default, or closed?
  • Column type dropdown labels: "Text · Number · Date" (current) or "Categorical · Numeric · Temporal" (more accurate)? Recommend Text/Number/Date — matches whitepaper §4.
  • Should we show a small sample value beside the Type select to help users confirm the type? e.g., "Date · sample: 2024-03-15"?
  • Action column width feels OK at 120px — confirm or wider?
